## 兼容与配置

1. `qdata.forwarding.allowed-hosts` / `allowed-cidrs` 默认均为空，因此升级后 API/GIS 转发需先登记实际业务目标。两类规则为“或”；精确域名规则信任其 DNS 地址，CIDR 规则要求全部 DNS 答案命中。链路本地、组播、未指定地址始终拒绝。IP 字面量同样校验；域名不支持通配符。不自动跟随 3xx。
2. Excel 外链、远端对象存储 URL、任意本地路径都不再下载；需迁为受管上传文件。不更改业务数据库中的历史图片字段。
3. Quartz 已登记 `ryTask`（三个示例方法）、`dppQuartzJob.dataIntegration/dataDevelopment`、`qualityTaskExecutorJob.runExecuteTask`、`mcTaskExecutorJob.runExecuteTask`、`daDatasourceServiceImpl.detectTableSchemaUpdates`，以及对应精确类名。新任务须经代码审查登记；未登记历史任务执行会拒绝。本次没有连接数据库盘点历史任务。
4. 镜像锁定清单为 `deploy/image-digests.json`：mysql:8.0、redis:7-alpine、rabbitmq:3.13-management、neo4j:5.26-community、nginx:1.28-alpine、eclipse-temurin:21-jre-jammy。三个服务 Dockerfile 均使用锁定 Temurin digest。浮动本地 tag 的 config 不匹配时不会直接使用。离线 archive 的 index/manifest/config/层校验保留在 `fetch-image.py`。
5. `deploy/frontend-install-scripts.json` 钉住 package-lock SHA256 与 @vue-office/docx、excel、pdf、vue-demi、v-code-diff 的安装入口和辅助脚本。全部先校验，再执行；默认关闭其他生命周期脚本。更新 lock/依赖须重新审查；不以自动更新摘要绕过校验。
6. 内网私有 HTTPS CA 需进入受管信任库。休眠 `sendSSLPost` 失败行为从返回空字符串变为异常；仓库无业务调用点。

配置与操作说明同时见 `docs/DEPLOYMENT.md` 和 `qdata-server/src/main/resources/application.example.yml`。
